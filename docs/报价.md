# 数据同步推送平台工时报价说明

## 一、项目概述

本项目为多人使用的数据同步推送平台，已实现登录鉴权、用户与权限管理、数据录入、Excel 导入、事件 Excel 导入后推送、记录查询、批次查询、推送管理、推送日志、媒体库规则维护、事件数据查询、导出功能、系统配置及客户接口联调等功能。

截至目前，项目已按客户接口需求完成 3 个版本的接口对接与调试。项目开发按 1 名开发人员计算，投入 5 个工作日，每日 10 小时，共计 **50 工时**。

## 三、主要交付功能说明

### 1. 数据库、服务器与基础环境

- 完成 MySQL 数据库连接及 Prisma 数据模型设计。
- 建立用户、角色、权限、数据记录、数据批次、推送任务、推送明细、媒体库、事件数据、系统配置和操作日志等核心数据表。
- 配置数据库迁移、错误详情字段、查询索引和数据库连接参数。
- 配置应用服务、环境变量、JWT、客户接口地址、推送 Token、超时和重试参数。
- 完成服务构建、启动与运行环境问题排查。

### 2. 用户、角色与权限

- 用户登录、退出、修改密码和登录会话验证。
- 用户新增、编辑、账号启用/禁用、个人资料及用户数据统计。
- 管理员与普通用户权限区分；普通用户仅能查询和推送本人创建的数据。
- 管理员可查看全量数据、管理用户、调整接口配置和执行管理操作。

### 3. 数据录入、导入与标准化

- 支持文本粘贴录入和 Excel 文件批量导入。
- 自动解析标题、正文、链接、作者、发布时间、互动数据等字段。
- 对必填字段、链接、数值和时间格式进行校验。
- 按来源平台、发布主体、账号类型完成标准化分类映射。
- 处理重复 `textId`，将可用数据保存为待推送记录。

### 4. 查询、筛选与详情查看

- 数据记录支持关键词、状态、来源、提交人、日期范围筛选和分页查询。
- 批次列表支持批次号关键词、导入方式、状态、日期范围筛选和分页查询。
- 推送日志支持状态、提交人、日期范围筛选，查看任务状态、请求体、响应体和失败原因。
- 用户列表支持关键词、状态和角色筛选。
- 媒体库支持名称、域名、作者、备注关键词及平台、主体、状态筛选。
- 事件数据支持分类筛选、关键词查询、时间范围筛选和详情查看。

### 5. 导出功能

- 支持数据记录 CSV 导出。
- 支持批次 CSV 导出。
- 支持推送日志 CSV 导出。
- 导出结果均按当前筛选条件输出，便于客户对账和内部归档。

### 6. 媒体库与事件数据

- 支持事件 Excel 数据查询、分类统计与导入后推送。
- 支持媒体/账号规则的新增、编辑、删除、启停和查询。
- 支持 backfill、lookup 等辅助接口，便于规则回填和查询匹配。

### 7. 推送、日志与异常追踪

- 支持单条推送、批量勾选推送及 Excel 导入后逐条推送。
- 支持 Bearer Token 鉴权、批次拆分、请求组装、状态流转和推送任务落库。
- 记录推送请求内容、接口响应、HTTP 状态、成功/失败数量、供应商响应码及单条失败原因。
- 支持失败任务重试、429/5xx 指数退避、超时处理、推送中状态重置和失败记录删除。
- 提供推送日志、批次详情、请求内容、响应内容和失败明细查看。

### 8. 多版本客户接口联调

- 完成客户接口第 1 版基础推送联调。
- 完成第 2 版字段枚举和请求结构适配。
- 完成第 3 版文档分析，提供 v2/v3 协议可配置切换能力。
- 完成 `crawlTime`、ISO 8601 时间格式和 curl 请求验证；定位并反馈 DNS、代理、超时及客户服务端 SQL 时间格式等问题。
