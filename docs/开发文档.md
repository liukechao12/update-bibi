# 数据同步推送系统开发文档

## 1. 项目目标

构建一个支持多人登录的数据同步推送平台，完成数据录入、字段标准化、批量推送、结果记录、人员管理与统计查询。

## 2. 核心功能

- 粘贴录入数据
- Excel 导入数据
- 自动检测新数据并推送
- 记录每次推送的请求、响应、重试与失败原因
- 支持按人员查看推送记录
- 支持角色权限控制
- 支持 UAT / 生产环境切换

## 3. 数据标准

系统将原始数据转换为对方接口要求的 `PushRequest`：

- `version`: 默认 `1`
- `records`: 每批最多 100 条
- `textId`: 唯一键
- `originType`: 统一映射为 `wb / wx / wz / sp / lt / app`
- 时间统一为 `YYYY-MM-DD HH:mm:ss`

## 4. 页面规划

- 登录页
- 仪表盘
- 数据录入页
- 批次管理页
- 数据明细页
- 推送日志页
- 人员管理页
- 角色权限页
- 系统配置页

## 5. 技术方案

- 前端：Next.js + React + TypeScript
- 后端：Next.js Route Handlers
- 数据库：Prisma + SQLite（开发阶段）
- 推送：后台异步任务 + 指数退避重试
- 鉴权：JWT

## 6. 推送策略

- 单批最多 100 条
- 5xx 自动重试，最多 5 次
- 429 读取 `Retry-After`
- 4xx 除 429 外不自动重试
- 每次推送保存完整请求和响应
